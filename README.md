# Stagenet token addresses

This repository records existing Token Metadata OnChain contract deployments on Midnight Stagenet (Midnight 2.x / ledger-v9).

The deployment set contains 11 contracts producing 16 token records. See the [Stagenet token metadata deployment record](stagenet-token-metadata-deployments.md) for addresses and deployment details.

Canonical contract sources live in [acedward/mip-erc7496-midnight-contracts](https://github.com/acedward/mip-erc7496-midnight-contracts). The migrated [MinoCrab reference](https://github.com/acedward/mip-erc7496-midnight-contracts/tree/dc437cc8e7bb2852b98406964a00397d2403cfdf/minocrab) and [benchmark reports](https://github.com/acedward/mip-erc7496-midnight-contracts/tree/dc437cc8e7bb2852b98406964a00397d2403cfdf/benchmarks) are pinned to commit [`dc437cc8`](https://github.com/acedward/mip-erc7496-midnight-contracts/commit/dc437cc8e7bb2852b98406964a00397d2403cfdf).
